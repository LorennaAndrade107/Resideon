# ResideOn

> Não é apenas estudar. É evoluir na sua jornada.

O **ResideOn** é um site de estudo para quem está se preparando para a residência na área da saúde. Ele reúne bibliotecas de materiais, casos clínicos, questionários e outros conteúdos de apoio, organizados por área.

O projeto é feito apenas com **HTML e CSS**.

## Áreas do site

- **Residência em Anestesiologia**: biblioteca, mapa do corpo, casos clínicos e questionários.
- **Residência em Psicologia**: biblioteca (livros, bases de dados, revistas e ordem de estudo ), casos clínicos e questionários.
- **Materiais de estudo**: mapa mental e videoaulas.

## Estrutura de pastas

resideon/
├── html/     páginas do site
├── css/      um arquivo de estilo para cada página
├── img/      capas de livros e logos
└── README.md


Cada página tem o seu próprio arquivo CSS, na pasta `css`.

## Como abrir o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta `html`.
3. Dê dois cliques em `inicio.html` para abrir no navegador.

Não é preciso instalar nada.

## Tecnologias

- HTML5
- CSS3
- Fontes do Google Fonts: Orbitron e Montserrat

## Identidade visual

O site usa tons de verde escuro com destaque em verde neon, definidos como variáveis no início de cada arquivo CSS (`:root`).
